# Resources

Generation inputs, generated assets, and IAT definitions.

## Directories

- [`stimuli_generation`](stimuli_generation): Source specifications for generating synthetic stimuli sets
- [`stimuli`](stimuli): Generated stimuli assets and their manifests
- [`iats`](iats): Published IAT definitions that assemble categories and stimuli

Together these directories define what to generate, store the generated outputs, and describe the tests presented by the backend.
