# Analysis resources

Checked-in collected datasets and report-ready CSV artifacts produced by the offline analysis CLI.

## Directories

- `collected/`: normalized collection files produced from evaluation results and the matching SQLite database
- `report/`: report-ready CSV summaries produced from `collected/`

Treat these files as generated artifacts. Regenerate them with [`apps/analysis`](../../apps/analysis/README.md) when evaluation results or the matching database change.
