# Apps

Application code for this repository.

## Directories

- [`analysis`](analysis): offline CLI for collecting evaluation datasets and generating thesis-ready text reports plus PNG figures
- [`api`](api): Generated TypeScript types for backend OpenAPI schemas
- [`backend`](backend): FastAPI backend that serves the frontend, published IAT catalog, stimuli, and participant session flow
- [`frontend`](frontend): Participant-facing single-page frontend that the backend serves
- [`stimuli_generator`](stimuli_generator): CLI and pipeline code for generating synthetic image stimuli from YAML specs under `resources/stimuli_generation/`
